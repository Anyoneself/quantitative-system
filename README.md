# Quantitative-System

Quantitative-System 是一个面向 A 股的本地股票分析助手，围绕两件事工作：筛选当前值得关注的买入候选，以及给已有持仓提供卖出风险建议。

网页提供总览、行情中心、买入卖出、自动化交易和系统设置。自动化交易目前是实盘草案与接入检查栏目，尚不能自动执行交易。组合实验、策略研究、回测、手工组合管理和前向模拟不再作为日常页面；已有底层引擎和历史数据保留，不混入真实账户。

## 日常使用的能力

### 总览与持仓卖出建议

展示同花顺同步的账户资金、持仓、资产配置和风险图表。每只持仓都有独立建议、依据、下一步关注条件、亏损提醒价、止盈观察价、仓位占比、可卖数量和行业信息；旧快照不能冒充当前建议。已授权后的行情逐只补充，先完成的股票立即发布，不等待所有持仓全部完成。

未授权公开行情时，仅在本机检查客户端显示价格与成本的盈亏，分别提示控制亏损、止盈观察、等待行情确认或核对成本。默认亏损提醒线为 8%，止盈观察线为 20%，不是用户风险承受能力的评估，也不是自动委托价；亏损越线优先于技术评分。授权后的完整判断复用收盘日线分析，参考价和账户盈亏仍取客户端显示值。达到止盈观察线本身不等于必须卖出，缺少数据时也不会默认建议持有。

### 行情中心的分析榜单

股票榜单提供涨幅 500、跌幅 500、跌停 100、涨停 100 四个股票池 TAB，首次打开默认涨幅池。500/100 是过滤板块后合格股票的入池目标：涨幅和跌幅分别按涨跌幅降序、升序选择 500 只主板股票；涨跌停在当日专用股票池内按成交额降序选择 100 只主板股票。创业板、科创板和北交所不占名额，沿同一榜单继续补足；遍历全池仍不足时，明确显示实际合格数量及缺额。每完成一只就推送进度和当时的 Top 10 榜单，不等待整批结束。所有有效分析结果按模型与量价评分排序，成功分析五只时就显示五行，超过十只后保留评分最高的十只。买入观察、继续观察、信号中性和暂不建议买进均保留原结论；入榜不代表达到买入条件，原买入判定不变。行情失败或数据不足不参与有效评分榜，也不计入成功分析数。列表展示股票名称、代码、行业、原榜入池排名、参考收盘价、行情日期、评分、结论、依据、风险，并可打开个股详情。

榜单风险仅展示最多两项主要风险和必要的数据缺失、缓存提示。详情在股票行内展开或收起，保留完整理由、风险、量价证据、后续观察和行情来源，不跳转单股分析，也不重新请求行情。逐股刷新及排名变化保留展开状态，股票离榜、重新分析或切换股票池时清除旧详情。

涨跌幅股票池来自新浪公开榜单，涨跌停股票池来自东方财富公开专用池，均不是同花顺客户端直读或人气热榜；与客户端可能有更新时点和排序差异。每轮按页读取，收满目标数量的合格股票即停止，最晚在来源声明的完整股票池末尾结束。校验页完整性、代码唯一性、跨页排序及涨跌停池日期和总数后固定本轮成员，补位页失败也不能将前页冒充完整结果。读取失败或日期不匹配时不回退其他股票池；当日未发布或休市时明确提示，日期正确的空池按零只显示。分页不构成同一时刻的原子快照，检测到重复或排序变化时要求重试。界面分别展示目标数量、合格入池数、成功分析数、失败数、排名检查数和板块排除数，并展示来源、读取时间与涨跌停池日期。失败股票不计入成功分析数；读取时间不冒充行情发布时间。入池仅限定研究范围，不代表买入条件或盈利概率；跌停不等于见底，涨停也不等于可成交。

分析中也可切换股票池。切换立即停止旧池派发、清空旧候选并读取新池，不等待旧池所有请求结束；启动期间连续切换也只保留最后选择的 TAB。分析共用有界线程池，旧池已经发出的网络请求结束或超时后释放线程，新池可使用空闲线程继续分析，切换不会叠加分析线程。旧任务结果、旧事件流及延迟响应均不会混入新池，同一股票的有效日线分析缓存仍可复用。

扫描默认使用八个并发任务并保留请求限速。同一日线时段、同一模型的成功分析最多缓存十五分钟，失败结果短暂缓存；跨收盘、跨日或切换模型后重新分析。可选资金流服务连续失败时短暂退避，不让每只股票重复等待同一故障，并明确注明资金流未参与评分。页面按证券代码复用榜单行，每完成一只股票独立刷新一帧进度和当时的 Top10，不合并快速到达的缓存结果。事件流保留本轮最近的逐股完成记录，连接建立前的快速完成也可补发；断流后按游标长轮询续接，不跳过中间结果，临时失败后继续重试。运行状态分别报告已处理、有效分析和失败数量，不把请求结束等同于有效分析完成。

公开市场批量筛选优先读取腾讯前复权日线，不可用时整段切换到东方财富前复权日线，榜单标注行情来源；不拼接不同来源的价格序列。在线来源均失败时，可使用上海时区同日、同收盘前后时段的腾讯原始留档，重新核对证券代码、请求参数、内容哈希、前复权序列和日期价格质量；榜单直接展示“本地缓存”及采集时间，不冒充实时行情。无合格缓存的股票记为“行情源不可用、待重试”，不计入已处理、成功或个股失败，也不缓存为失败结果；保留其他股票的有效榜单，并允许手动重试。访问拦截等不可恢复响应不反复重试，故障来源短暂退避，不生成虚假候选。此备用路径仅用于公开股票池扫描，不改变持仓公开行情的腾讯单一来源授权。

行业来自新浪公开行业分类，按全市场板块分页批量读取并缓存一天，保留来源和读取时间，不向该来源发送私人持仓清单。行业未获取、过期或分类冲突时明确标记，不推测行业。行业缓存与账户快照独立，公开行业目录会在总览连接检查或行情筛选时后台更新。

当前不分析创业板、科创板和北交所，使用最近完整日线而非实时盘口；超过七个自然日的历史行情不进入筛选。首次读取日线仍受提供方限速及可用性影响，进行中的排名仅反映股票池内已分析结果，不是完整市场结论；重复打开不会重启正在运行的筛选，用户可停止或重新更新。没有候选、接口失败和覆盖不完整分别显示，不把失败当成买入机会。

### 单股算法选择

单股分析提供 9 种算法：KNN、加权 KNN、时间衰减 KNN、稳健集成、逻辑回归，以及基于 scikit-learn 的随机森林、极端随机树、梯度提升树和高斯朴素贝叶斯。输入股票后切换算法会重新分析，旧请求不会覆盖新选择，结果标明实际算法和预测周期；样本不足或依赖缺失时明确报告，不静默替换模型。股票榜单仍默认使用稳健集成，不受单股选择影响。

新模型共用已有量价特征、T+1、交易费用与滑点约束，使用五个交易日的扣费后收益至少 1.2%、期间回撤小于 6% 的达标标签。只训练截至分析时点已完成的历史标签，预处理不使用当前待预测样本；至少二十个有效样本，正负标签各不少于五例，固定随机种子并限制模型规模。概率向历史基准收缩以降低极端输出，但不等于校准或有效性验证；可以接入已有时间顺序样本外评估，新算法尚未通过真实市场有效性验收，不承诺盈利。

### 买入卖出与客户端衔接

独立栏目支持准备沪深主板股票的买入或卖出草稿，从持仓、自选股选择证券，手动填写限价和数量。每次核对重新读取同花顺当前资金与持仓，检查买入整手、资金余量、可卖数量和零股约束；不自动使用复权行情价格，也不默认卖出全部持仓。

核对结果始终标记为“未提交”，可以分别复制代码、限价和数量，并打开同花顺由用户手动填写、核验账户及确认交易。修改输入、离开栏目、快照变化或核对超过60秒都会使草稿失效。手续费预留不代表真实佣金，账户编号尚未核验，草稿不是券商预受理结果；自动填单、真实下单、撤单和委托成交回报尚未接通。

### 全自动实盘准备

独立栏目保存用户明确填写的投入上限、单笔买入上限、单股仓位上限、单日亏损停机线、交易白名单及买卖规则说明，并明确是否允许卖出现有持仓。金额使用十进制校验，单笔上限不超过单股配置额度；不预填资金限额，不将行情榜单自动转换成买入指令。草案保存在本机，更新校验版本以防其他页面覆盖，保存、刷新或服务重启均不启动交易。

接入检查区分账户只读状态、账户身份与权限、下单撤单和成交回报、实时未复权报价及交易日历、可执行策略及订单风控。当前交易通道和执行器均未实现，启动在前后端保持阻断；规则文字尚未转为可执行策略，所填风险限额也不是已生效的交易保护。该栏目不是已完成的全自动实盘系统，不用模拟成交冒充实盘结果。

### 系统设置中的客户端连接

同花顺启动、权限、账户同步、自选分组同步及公开持仓行情授权集中在系统设置。持仓证券代码只在用户允许后发送到腾讯查询，不发送账户金额、数量或登录信息。同步与建议仅供人工参考，不自动下单。

## 快速启动

### 环境要求

Python 3.10 及以上；机器学习依赖 scikit-learn，安装项目时会自动安装。Windows 还需要 IANA 时区数据，以支持 `ZoneInfo("Asia/Shanghai")`。macOS 与 Linux 通常自带时区数据库。浏览器验收脚本额外需要 Node.js 与 Playwright。

```bash
python -m pip install tzdata   # 仅 Windows 需要
```

### 启动 Web 界面

```bash
git clone https://github.com/Anyoneself/quantitative-system.git
cd quantitative-system
python -m pip install -e .
export PYTHONPATH=src          # Windows PowerShell：$env:PYTHONPATH = "src"
python -m web                  # 默认 http://127.0.0.1:8000
```

浏览器打开 <http://127.0.0.1:8000> 即可使用；左侧边栏可进入总览、行情中心、买入卖出、自动化交易与系统设置。实盘启动尚未接通。

- 首次启动会自动初始化数据库，默认落在 `data/app/quantitative_system.db`，可用 `QUANT_DB_PATH` 指定其他位置。
- 默认端口被占用时会自动顺延尝试 8001 至 8010；也可以显式指定，例如 `python -m web --host 127.0.0.1 --port 8080`。
- 服务默认只监听本机回环地址，不对外网开放。
- macOS 与 Linux 还可以用 `./scripts/quant web` 启动，Windows 在 Git Bash 中用法相同，在 PowerShell 或 cmd 中则用 `scripts\quant.cmd web`；两者都会自动设置 `PYTHONPATH`。
- 安装为本地命令后可直接使用 `quant-web`：`python -m pip install -e .`。

### 使用命令行

```bash
python -m cli advise 600519                  # 单股买卖观察
python -m cli sell 600519 --cost-price 1500  # 持仓卖出风险
python -m cli backtest 600519                # 单股回测
python -m cli evaluate 600519                # 走步验证与样本外表现
python -m cli scan --pool-file config/stock_pool.example.txt --once
python -m cli research --demo                # 组合实验（合成数据，不代表真实业绩）
```

macOS 与 Linux 同样可以用 `./scripts/quant advise 600519` 等形式调用，Windows 用 `scripts\quant.cmd advise 600519`。`--demo` 使用合成数据，只用于验收工程链路，不是实际业绩。

### 使用容器

```bash
docker compose up --build
```

服务地址同为 <http://127.0.0.1:8000>；绑定地址与端口通过 `.env` 中的 `QUANT_WEB_BIND`、`QUANT_WEB_PORT` 调整（参考 `.env.example`），数据保存在 `quant-data` 卷。容器启动前会先执行幂等数据库迁移。

### 运行测试

```bash
export PYTHONPATH=src          # Windows PowerShell：$env:PYTHONPATH = "src"
python -m unittest discover -s tests -t tests
```

上述命令覆盖数据质量、分析、回测、组合实验、存储、接口与页面结构等测试。项目结构与各文件职责见 `doc/artecture.md`。

## 保留的底层能力

### 整理可信的研究数据

采集免登录公开行情和资金流，保留原始响应，检查日期、价格和成交量异常。区分研究使用的复权价格与组合估值使用的未复权价格；多证券研究要求明确的历史证券池快照，避免直接用当前股票池代替历史成员。

组合行情采集固定使用新浪未复权日线，成交额明确标为估算值。今天选定的证券池只从今天登记；历史研究需另外提供有来源和已知日期的历史成员记录。提供方修改已冻结的旧行情时，系统阻断更新，不悄悄重写既有结果。

后续采集窗口扩大时，窗口前的额外历史不会进入已冻结输入；观察期内的删除、回填和价格修订仍会阻断更新。

数据体检检查声明交易日历与基准的差异、成员行情缺日及异常开盘跳变。没有独立日历时明确标记未核验，不把行情缺失自动当成休市或停牌。日历声明可以包含未来日期，但不能改写已观察区间；填写来源不等于已经验证来源。

### 分析单股与持仓

结合技术指标、量价形态、资金流、背驰信号和机器学习分数，生成股票观察结果及风险提示。对于已有持仓，结合成本、目标收益和亏损约束，辅助复盘持有、减仓、止盈和止损的依据。

### 检验策略是否经得起验证

按时间顺序划分训练和测试阶段，在测试前冻结参数，观察未参与选参的数据上的表现。支持单股回测和多证券组合实验，关注成本后收益、回撤、波动、成交数量及不同时间阶段的一致性，而不只看历史胜率。

组合实验另保留最终时间留出期，延续现金、持仓和风控状态，单独检查成本后收益及双倍成本压力。报告记录同一数据快照的重复实验次数，并提示反复查看、调参会削弱留出期的独立性。历史置信区间不等于未来盈利概率。

### 模拟交易约束与风险控制

模拟信号产生后的成交，考虑费用、滑点、停牌、涨跌停和 T+1 等约束。组合实验进一步限制仓位和成交容量，记录部分成交、拒单、回撤熔断、单日亏损暂停及行情陈旧事件，并比较成本上升后的策略表现。

### 复盘组合与保存研究证据

记录组合交易流水，重建现金、持仓和净值，展示资产配置与风险指标。每次组合实验保留所用数据、参数、订单、净值和验收结果，让成功与失败的研究都能够追溯和复现。

组合模拟增加独立对账，从订单重新计算现金、费用、持仓、日终权益与已实现及未实现盈亏。重复订单、费用或资金不一致会中止模拟；逐证券净盈亏与组合权益变化交叉核对。这是本地模拟账本检查，不是券商成交对账，也不证明实际成交可实现。

### 持续观察冻结后的策略

在收盘后登记真实未复权行情、证券池和策略参数，提前记录下一交易日的目标权重。持久化前向模拟支持每日推进和本机定时观察，复用回测的成交与风控规则，但与真实账户完全分离。观察进程需持续运行；页面自动检查仅在页面可见时工作。

账本采用原子保存、进程互斥和连续版本链，重复推进不会重复记账。代码或历史行情变动、盘中数据和过期数据会阻断推进；观察失败保留资金持仓并记录原因。漏跑后的历史补算单独标记，不计为按时完成的前向观察。熔断后仅尝试模拟退出，手动暂停保留全部记录。

预登记信号约束正常调仓，但执行日新触发的行情陈旧熔断可以优先将目标仓位降为零。系统记录风控覆盖原因，仍按实际行情决定能否成交；该例外不能授权新的买入或提高风险敞口。

主账本损坏或发布中断后，只能显式恢复最新完整版本，不能选择较早盈利记录回退。恢复后默认暂停，继续观察会永久标记证据缺口，并保留原有熔断状态。版本链与账本位于同一本机，不能替代异机备份、第三方审计或灾难恢复。

运行面板显示后台观察心跳、离线和过期状态、更新错误及近期存档版本。心跳独立于资金账本，刷新状态不产生新的模拟交易或账本版本；后台观察进程退出后不会显示为仍在运行。

页面操作携带账本版本，后台先一步完成更新时，旧操作被拒绝并要求重新核验。读取与写入互斥，写入中的记录显示为更新中，不会被误报为损坏并提示恢复。

### 检查每日表现与执行偏差

前向净值与同期基准收盘价格对齐，展示累计超额收益、最近二十个估值日的超额、主动风险和信息比率。基准是未扣成本、不含分红的价格收益，不冒充可投资组合；样本不足或主动收益零方差时，相关统计明确留空。

每日体检同时呈现实际持仓与下一目标、日终敞口、陈旧估值、部分成交、拒单原因，以及相对开盘价的模型价差。目标信号不再被当作已经实现的仓位，模型成交成本也不被当作真实券商成交质量。

证据检查同时关注观察日数、中断、账本平衡、估值有效性、熔断、成本后收益和相对基准表现，提供可导出的完整观察报告。检查通过仅代表可进入人工复核，不会自动开放实盘或承诺未来盈利。

### 连接本机同花顺

支持启动本机同花顺、检查客户端和辅助功能权限，并从已登录的平安证券交易持仓页读取资金与持仓快照。快照单独展示，不导入模拟组合账本，不保存账号密码或登录令牌，也不保存到账户数据文件。总览或连接页可见时，默认每三十秒自动读取并分析，可随时关闭；读取失败或超过有效期时明确标记旧数据。

总览仅展示已同步的客户端资金、持仓、自选股及读取时间。账户同步成功后自动计算股票仓位、最大单股占总资产比重和当前不可卖占比，在风险雷达上显示；快照过期仍保留历史值并明确提示，不与账本数据混合。

经用户明确允许后，系统仅向腾讯公开行情接口发送持仓证券代码及沪深300基准代码，不发送账户标识、资产金额、数量或登录信息。授权仅在本次服务运行期间有效，可撤销，清空快照也会撤销。未授权时只分析本地资产结构；公开行情失败不影响资金与持仓同步。

历史风险以当前总资产权重逐日重放公开收盘价格，估算年化波动、单日历史 VaR(95%) 和相对沪深300的 Beta，同时展示归一化情景曲线。它假设每日维持当前权重，资产差额收益为零，不含交易成本，不能当作账户历史净值、实际收益、交易胜率或未来预测；公开复权数据和交易日历未独立核验，VaR 也不是未来亏损上限。

分析只使用快照时点之前已收盘的行情，要求至少二十个连续共同日收益，最多取二百五十二个；持仓超过二十只、行情缺失、样本不足或基准距今超过七个自然日时，仅保留能可靠计算的结构指标，不把缺失值填零。雷达量程是绘图刻度，集中度分级是系统提示阈值，不是盈利评分。公开行情有短期缓存，账户快照与风险报告仅存内存。

自选股从客户端分组设置页读取当前选中组，核对分组、证券代码、名称及声明总数，不从自绘行情表猜测缺失值，也不混用旧账户缓存。自选与持仓有独立的读取时间、错误和过期状态；切换分组后同步会替换前一分组，不声称已经同步所有分组。

有效快照中的股票可带入行情分析，持仓同时带入正数成本及数量。切换至自选股会清除之前的持仓输入，过期快照禁止带入；账户与行情研究仍保持分离，不自动生成交易。两类自动读取互斥，依赖对应客户端页面就绪，不会在后台切页、输入密码或执行任何交易。

当前适配 macOS 同花顺 5.3.5（7.0.62）的只读页面结构，客户端版本变化、权限不足、页面未就绪、金额隐藏或持仓市值无法核对时停止更新。这里同步的是客户端显示值，不保证行情实时性，也不将界面读取等同于官方账户接口。

### 系统设置

「系统设置」页集中本机环境说明，并提供同花顺客户端官方下载中心的 macOS 与 Windows 下载链接。链接只是来源指引，下载与安装由本机浏览器和用户自行完成；页面同时标明只读连接当前仅适配 macOS 的「应用程序/同花顺.app」，Windows 客户端尚不能被识别。

## 当前边界

- 系统用于研究、模拟、复盘及经用户授权的本机账户只读查询，不执行真实交易。
- 同花顺 OAuth 回调、全分组后台同步、行情流、成交回报、真实下单和撤单尚未接入；没有已验证接口的操作保持阻断。
- 客户端读取需要用户自行完成登录并授权 macOS 辅助功能；账户唯一标识尚未验证，快照不得用于订单决策或跨账户对账。
- 已具备前向模拟的工程闭环，尚未积累足够真实市场观察记录或完成盈利验证，不承诺稳定盈利。
- 前向模拟以至少 126 个观察日作为初步证据门槛，而不是盈利保证或实盘许可；数据与接口条件未满足时不会自动创建有效观察。
- 日线模拟不代表开盘真实可成交；本地哈希也不是第三方审计或可信时间戳。
- 历史证券状态、公司行动和退市处理仍不完整，日线模拟也不能完整还原盘口与实际成交。
- 模型分数和历史回测结果不是收益承诺；合成演示数据不是实际业绩。
- 研究检查通过不等于具备实盘条件，数据不足或验证失败会明确展示。
