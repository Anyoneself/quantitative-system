# 背驰信号说明

本文档说明当前背驰模块的实际实现，以及它如何参与买入、卖出和入场扫描。

## 1. 定位

背驰用于识别：

```text
价格接近新低或新高，但 MACD、量能或资金流没有同步强化。
```

当前系统输出：

```text
下跌背驰候选
上涨背驰候选
多空背驰分歧
无明显背驰
```

背驰是候选信号，不是反转保证。

## 2. 样本要求

默认 `lookback = 30`。

最少样本：

```text
max(lookback + 35, 60)
```

默认情况下至少需要 `65` 个交易日。

## 3. 使用字段

背驰模块使用：

- 收盘价。
- 成交量。
- MACD DIF。
- MACD DEA。
- MACD 柱。
- MA5。
- MA10。
- 资金流信号，可选。

## 4. MACD 计算

代码内部重新计算 MACD：

```text
EMA12
EMA26
DIF = EMA12 - EMA26
DEA = DIF 的 9 日 EMA
MACD 柱 = 2 * (DIF - DEA)
```

## 5. 下跌背驰候选

基础位置：

```text
近 30 日价格区间波动 >= 5%
当前收盘价 <= 前 30 日最低收盘价 * 1.01
```

加分和置信度：

- 当前 MACD 柱强于前低对应 MACD 柱：买入调整 `+8`，置信度 `+28`。
- 当前 DIF 强于前低对应 DIF：买入调整 `+6`，置信度 `+22`。
- 当前下跌量能弱于前低量能：买入调整 `+3`，置信度 `+10`。
- 资金流不再持续流出：买入调整 `+4`，置信度 `+12`。
- 空头排列末端多次 MA5/MA10 反复交叉：买入调整 `+4`，置信度 `+10`。

买入调整分最终限制在 `0` 到 `20`。

当买入调整分不低于 `8` 时，判定为下跌背驰候选。

## 6. 上涨背驰候选

基础位置：

```text
近 30 日价格区间波动 >= 5%
当前收盘价 >= 前 30 日最高收盘价 * 0.99
```

加分和置信度：

- 当前 MACD 柱弱于前高对应 MACD 柱：卖出风险 `+8`，置信度 `+28`。
- 当前 DIF 弱于前高对应 DIF：卖出风险 `+6`，置信度 `+22`。
- 当前上涨量能弱于前高量能：卖出风险 `+3`，置信度 `+10`。
- 高位背驰同时主力资金持续流出：卖出风险 `+5`，置信度 `+14`。
- 多头排列后多次 MA5/MA10 反复交叉：卖出风险 `+4`，置信度 `+10`。

卖出风险调整分最终限制在 `0` 到 `25`。

当卖出风险调整分不低于 `8` 时，判定为上涨背驰候选。

## 7. MA5/MA10 反复交叉状态

背驰模块会统计最近最多 40 个有效交易日中，MA5 和 MA10 的交叉次数。

字段：

```text
ma5_above_ma10
ma5_ma10_weaving
ma5_ma10_weaving_count
ma5_ma10_first_bullish_weaving
ma5_ma10_late_bearish_weaving
```

说明：

- `ma5_ma10_weaving` 表示 MA5 与 MA10 当前距离接近，或近期至少交叉 2 次。
- 这些字段保留在结果对象中，当前主要用于背驰评分解释。

## 8. 买入评分接入

`generate_advice()` 中：

- 下跌背驰候选会增加买入评分。
- 上涨背驰候选会进入风险提示。
- 背驰依据会写入 `evidence`。

输出示例：

```text
背驰信号：下跌背驰候选，置信度 60
买入评分调整：+17
卖出风险调整：+0
```

## 9. 卖出评分接入

`build_sell_advice()` 中：

- 上涨背驰候选增加卖出风险。
- 下跌背驰候选降低部分卖出风险。
- 无明显背驰只作为观察信息。

## 10. 入场扫描接入

`entry-scan` 使用背驰作为硬条件：

```text
必须存在 bullish_divergence
置信度 >= min_confidence
成交额 <= max_amount
成交额 / 20 日均额 <= max_amount_ratio
```

默认参数：

```text
max_amount = 50000000
max_amount_ratio = 0.8
min_confidence = 40
```

排序：

```text
背驰置信度越高越靠前
成交额比例越低越靠前
综合评分作为辅助排序
```

## 11. 使用边界

- 背驰不是反转确认，只说明动能可能衰竭。
- 低成交额可能意味着抛压减弱，也可能意味着流动性不足。
- 下跌背驰后仍可能继续下跌。
- 上涨背驰后仍可能继续上涨。
- 最好结合资金流、20 日均线、成交量和风险控制一起使用。
