# 量价信号认知边界

本文档说明当前系统如何理解价格和成交量，以及这些信号在代码中的实际落地方式。

## 1. 基本原则

价格反映方向，成交量反映参与强度。系统不会因为单一形态直接给出确定买卖结论，而是把多个信号合并到评分和风险提示中。

当前所有判断都基于日线级别：

- 不看盘口。
- 不看分钟线。
- 不看新闻和基本面。
- 不下单。

## 2. 放量突破

代码条件：

```text
收盘价 > 前 20 日最高价
成交量 / 5 日均量 > 1.5
```

解释：

- 价格突破近期压力。
- 成交量放大，说明有资金参与。

风险：

- 高位放量突破可能是加速末端。
- 次日如果放量回落，突破可靠性下降。

系统处理：

- 写入买入理由和数据证据。
- 作为股票池扫描排序的评分背景之一。

## 3. 缩量回调

代码条件：

```text
-4% <= 当日涨跌幅 < 0
成交量 / 5 日均量 < 0.8
收盘价 > 20 日均线
```

解释：

- 回调幅度不大。
- 抛压相对有限。
- 仍保持在短中期趋势线上方。

系统处理：

- 买入侧作为正面理由。
- 卖出侧降低风险评分。

## 4. 放量下跌

代码条件之一：

```text
当日涨跌幅 < 0
成交量 / 5 日均量 > 1.5
```

如果同时跌破 20 日均线：

```text
当日涨跌幅 < -2%
收盘价 < 20 日均线
成交量 / 5 日均量 > 1.5
```

解释：

- 下跌中卖压增强。
- 跌破 20 日均线时，趋势破坏风险更高。

系统处理：

- 买入侧写入风险提示。
- 卖出侧显著增加风险评分。

## 5. 高位放量滞涨

代码条件：

```text
abs(当日涨跌幅) <= 2%
成交量 / 5 日均量 > 1.5
近 20 日涨幅 > 30%
```

解释：

- 前期涨幅较大。
- 放量但价格推进有限。
- 可能出现筹码松动。

系统处理：

- 买入侧提示追高风险。
- 卖出侧增加止盈或减仓风险。

## 6. 低位止跌反弹

相关条件：

```text
收盘价 <= 前 20 日低点 * 1.06
短期已有回撤
出现十字星或长下影线
当日跌幅不大于 3%
```

十字星：

```text
实体 / 全天振幅 <= 0.18
```

长下影：

```text
下影线 / 全天振幅 >= 0.45
下影线 > 上影线 * 1.4
```

解释：

- 低位出现承接迹象。
- 只能说明下跌可能缓和，不能确认反转。

系统处理：

- 买入侧增加观察理由。
- 卖出侧降低部分风险，避免低位机械割肉。

## 7. 年线信号

年线需要至少 250 个交易日。

正面信号：

```text
收盘价 > MA250
MA250 > MA250_prev
放量上涨
```

强势回档信号：

```text
收盘价 > MA250
收盘价 <= MA250 * 1.04
-5% <= 当日涨跌幅 < 0
成交量 / 5 日均量 < 0.8
```

风险信号：

```text
收盘价 < MA250
```

系统处理：

- 放量站上年线加分。
- 年线上方缩量回踩加分。
- 低于年线扣分并提示长期趋势尚未修复。

## 8. 涨停缩量

代码条件：

```text
1 日涨跌幅 >= 9.8%
成交量 / 5 日均量 < 0.8
```

解释：

- 当日卖压较小。
- 但连续极端涨停后的缩量并不等于低风险。

系统处理：

- 写入正面理由。
- 后续观察是否放量开板并收弱。

## 9. 流动性

低流动性条件：

```text
20 日平均成交额 < 5000 万元
```

解释：

- 小成交额股票可能更容易剧烈波动。
- 买入和卖出都可能受滑点影响。

系统处理：

- 买入侧写入风险。
- 入场扫描会主动寻找低成交额，但必须结合流动性风险理解。

## 10. 背驰与成交额

入场扫描关注：

```text
下跌背驰候选
当日成交额较低
当日成交额低于 20 日均额
```

这类信号的含义是：

- 价格低位附近。
- MACD 或量能没有继续恶化。
- 抛压可能衰竭。

但低成交额也可能表示关注度不足，所以需要后续确认：

- 是否重新站上短期均线。
- 是否出现温和放量上涨。
- 资金流是否不再持续流出。

## 11. 使用建议

- 分数只是排序工具，不是交易指令。
- 买入前至少同时检查趋势、成交量、资金流和风险提示。
- 持仓后应单独看卖出风险评分，而不是只看买入评分。
- 回测结果只能说明历史表现，不能代表未来收益。
