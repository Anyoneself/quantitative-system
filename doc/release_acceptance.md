### 回测、组合与风险

- 收盘后产生信号、下一交易日开盘成交。

- 组合、交易流水、持仓重放、净值重建和基准对比。
- `request_id` 数据库唯一约束和并发幂等响应。
- 账本版本与行情内容指纹校验；过期净值返回 `STALE`，不展示旧风险值。
- 年化波动率、Sharpe、Beta、历史 VaR、完整持仓周期胜率和盈亏比。
- 未来日期、非交易日、未验证交易日、控制字符、非法 UTF-8、孤立代理项和金额越界拒绝。

### 前端、API 与部署

- 白色响应式仪表盘。
- 行情中心、策略研究、策略回测、投资组合和组合总览。
- 多组合切换及请求顺序保护，防止旧响应覆盖当前组合。
- 组合创建、交易录入、幂等重试、行情刷新和错误状态展示。
- 原生 Python HTTP API，无额外运行依赖。
- 非 root Docker 镜像、健康检查、Compose 本机绑定和命名数据卷。

## 4. HTTP 端到端验收

使用独立临时数据库和真实公开行情完成以下流程：

| 场景 | 结果 |
|---|---|
| 健康检查 | `200`，数据库 `ready` |
| 创建两个不同组合 | `201`，资产与基准互不串线 |
| 首次录入交易 | `201`，只写入一条流水 |
| 相同 `request_id` 原样重试 | `200`，`idempotent_replay=true` |
| 相同 `request_id` 改变交易内容 | `409` |
| 未来交易日期 | `422` |
| 组合详情和仪表盘刷新 | 持仓、现金、净值与交易数一致 |
| 模型评估接口 | `200`，包含样本外发布状态和原因 |
| 回测接口 | `200`，包含费用后净值和完整交易指标 |

并发提交相同组合、相同内容和相同 `request_id` 时，数据库最终只有一条流水，两个请求分别得到“新建”和“重放”语义。

## 5. 真实样本外结果

以下结果使用 `robust_ensemble`、5 个交易日标签和同一套冻结规则。测试区间均为 2026-02-09 至 2026-07-21。收益已经计入默认比例佣金、卖出印花税和双向滑点。

| 股票 | 冻结阈值 | 测试样本 | 入选 | Precision | 基准达标率 | Lift | 入选平均净收益 | 发布状态 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| 600519 | 0.25 | 22 | 17 | 17.65% | 27.27% | 0.647 | -1.259% | `FAILED_OOS` |
| 601988 | 0.45 | 22 | 5 | 20.00% | 40.91% | 0.489 | 0.372% | `FAILED_OOS` |
| 600036 | 0.25 | 22 | 7 | 28.57% | 27.27% | 1.048 | 0.259% | `RESEARCH_ONLY` |
| 000001 | 0.30 | 22 | 1 | 0.00% | 40.91% | 0.000 | -1.639% | `NOT_READY` |

结论：

- 600519 的成本后平均净收益为负，未通过样本外验收。
- 601988 虽然平均净收益为正，但 Precision 低于无筛选基准，未通过验收。
- 600036 仅略高于基准，入选只有 7 笔，仍只能作为研究证据。
- 000001 只有 1 笔入选，样本不足。

这段测试数据已经用于本次验收。以后如果根据这些结果修改特征、模型、标签或阈值，必须使用更晚的未见数据重新验收，不能继续把同一区间称为最终样本外测试。

## 8. 发布边界

当前版本适合：

- 本地研究和可复现的样本外检查。
- 单股规则回测。
- 手工组合账本、净值与风险复盘。
- 在模拟资金中持续收集前向结果。

当前版本不适合：

- 直接连接真实资金或自动下单。
- 将当前股票池结果解释为已消除幸存者偏差。
- 依赖完整历史 ST、停复牌、指数成分和公司行动的机构级回测。
- 高频、盘口级、部分成交或冲击成本建模。
- 多用户高并发服务。

因此，V1 软件工程交付已经完成；策略仍处于研究阶段。下一轮提高胜率的工作应从积累新的未见样本、补全点时数据和组合级验证开始，而不是继续在本次测试区间上调参。
