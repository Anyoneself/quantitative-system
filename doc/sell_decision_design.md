# 持仓卖出判断说明

本文档说明当前卖出模块的真实实现。

## 1. 定位

买入评分回答：

```text
这只股票是否适合买入观察？
```

卖出评分回答：

```text
如果已经持有，现在继续拿、减仓、止盈还是止损？
```

卖出模块只做风险辅助，不保证卖在最高点。

## 2. 输入

CLI：

```bash
./scripts/quant sell 601988 --cost-price 5.20
```

主要参数：

- `symbol`：股票代码。
- `cost_price`：持仓成本价。
- `quantity`：持仓数量，可选。
- `max_loss_rate`：最大可承受亏损比例，默认 `0.08`。
- `target_profit_rate`：目标止盈比例，默认 `0.20`。

如果没有成本价，Web API 可以返回 `NO_POSITION` 技术风险提示；CLI 的 `sell` 命令要求必须输入 `--cost-price`。

## 3. 输出

`SellAdvice` 包含：

```text
action
sell_risk_score
holding_return
reasons
risks
observations
key_levels
indicators
patterns
fund_flow
divergence
```

动作：

```text
HOLD         继续持有
REDUCE       减仓观察
TAKE_PROFIT  止盈或分批减仓
STOP_LOSS    止损
NO_POSITION  仅技术风险提示
```

关键位：

- 持仓成本价。
- 当前收盘价。
- 20 日均线。
- 年线 MA250。
- 近 20 日最高收盘价。

## 4. 持仓收益率

```text
holding_return = (当前收盘价 - 持仓成本价) / 持仓成本价
```

如果收益率小于等于负的最大亏损比例：

```text
卖出风险 +35
```

## 5. 技术风险评分

主要加分项：

- 放量跌破 20 日均线：`+25`。
- 收盘价低于 20 日均线：`+12`。
- 收盘价低于年线：`+20`。
- 高位放量滞涨：`+15`。
- 高位放量下跌或价格下跌放量：`+12`。
- MACD 死叉：`+8`。
- MACD 柱体走弱：`+4`。
- 近 20 日涨幅超过 `30%`：`+10`。

主要减分项：

- MACD 金叉：`-4`。
- 缩量回调且仍在 20 日均线上方：`-10`。
- 低位止跌反弹：`-6`。
- 价格在年线上方且年线向上：`-8`。

评分最终限制在 `0` 到 `100`。

## 6. 资金流风险

资金流接入规则：

- `持续流出`：卖出风险 `+10`。
- 5 日主力净流出且放量跌破 20 日均线：额外 `+15`。
- 5 日主力净流入且缩量回调：卖出风险 `-6`。

资金流不可用时，系统会在观察点中提示，不阻断卖出判断。

## 7. 背驰风险

背驰接入规则：

- 上涨背驰候选：增加对应 `bearish_risk_adjustment`。
- 下跌背驰候选：降低部分卖出风险，降低值在 `3` 到 `8` 之间。
- 无明显背驰：只提示暂未改变评分。

## 8. 移动止盈和目标止盈

近 20 日最高收盘价回撤：

```text
drawdown_from_recent_high = (近 20 日最高收盘价 - 当前收盘价) / 近 20 日最高收盘价
```

如果回撤不低于 `8%` 且持仓仍盈利：

```text
卖出风险 +12
```

如果持仓收益率达到目标止盈比例，并且存在高位风险：

```text
卖出风险 +15
```

## 9. 动作映射

```text
亏损超过最大亏损比例且评分 >= 50 -> STOP_LOSS
盈利达到目标止盈且高位风险存在且评分 >= 30 -> TAKE_PROFIT
评分 >= 70 -> 亏损为 STOP_LOSS，盈利为 TAKE_PROFIT
评分 >= 50 -> 亏损为 STOP_LOSS，盈利为 TAKE_PROFIT
评分 >= 30 -> REDUCE
其他 -> HOLD
```

## 10. 使用边界

- 卖出建议不考虑用户总资产和单票仓位占比。
- 当前没有 ATR 动态止损。
- 当前没有跟踪历史最高浮盈，只使用近 20 日最高收盘价。
- 卖出模块不直接下单。
- 成本价错误会直接导致收益率和动作失真。

## 11. 建议使用方式

- 先看是否触发硬止损。
- 再看是否有趋势破坏：放量跌破 20 日均线、跌破年线。
- 盈利较大时重点看高位放量滞涨、上涨背驰和回撤。
- 如果只是缩量回调且仍在趋势线上方，不应机械卖出。
